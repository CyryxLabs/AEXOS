**Method source, and what kind of source it is.** The construction method applied here is
published by Alex Hormozi in *$100M Offers* (2021), with lead-flow mechanics from *$100M Leads*
(2023), named separately. These are **practitioner manuals with a track record** — method
distilled by an operator from their own operating history. They give structure and sequence:
what an offer is made of, in what order, and which part to fix first. They do not give a sampled
population, a control condition or dispersion, so **no figure in them is an estimate of what will
happen here**.

That is a different class of evidence from the research programmes the rest of this squad runs on
— Sharp reporting Ehrenberg-Bass, Binet and Field analysing the IPA Databank. Both are legitimate.
They are not interchangeable, and this document keeps them distinguishable by tagging every claim
with its class.

## 3. The value equation

[CLASS: PRACTITIONER HEURISTIC — Hormozi, *$100M Offers*, 2021]

Perceived value rises with the dream outcome and the buyer's perceived likelihood of achieving
it, and falls with the time delay before the outcome and the effort and sacrifice required.
The relationship is structural. **No weights are assigned to the terms here, and none should be
invented** — the source states the relationship, not a formula with coefficients.

### 3.1 Numerator

| Term | Current state | What raises it | Owner of the fix | Evidence class |
|---|---|---|---|---|
| **Dream outcome** — what the buyer wants to be true afterwards, in their words | | | | |
| **Perceived likelihood of achievement** — why *this* buyer should believe it works for *them* | | | | |

> **Integrity line on the numerator.** The outcome described must be one the product produces
> today. Roadmap is disclosed as roadmap with no implied date. Proof must be real and
> attributable. Inflating the promise raises the claim and lowers perceived likelihood at once,
> which usually nets negative — and fabricated proof is a §6 BLOCK, not a weak choice.

### 3.2 Denominator

| Term | Current state | What lowers it | Owner of the fix | Evidence class |
|---|---|---|---|---|
| **Time delay** — from payment to the first outcome the buyer can feel | | | | |
| **Effort and sacrifice** — what they must do, learn, migrate, abandon or risk | | | | |

> **The denominator is where offers are usually lost and rarely worked.** Raising the promise is
> a writing task; lowering time and effort is an operations task and often a product one. An
> offer diagnosis that touched only §3.1 has not been done. Where the fix is product work, route
> to `@pm` — it does not happen in this document.

### 3.3 Binding term

`DREAM OUTCOME` / `PERCEIVED LIKELIHOOD` / `TIME DELAY` / `EFFORT AND SACRIFICE` — name **one**,
with the evidence that selects it.

## 5. Guarantee and risk reversal

[CLASS: PRACTITIONER HEURISTIC — Hormozi, *$100M Offers*, 2021 — taxonomy only]

| Field | Entry |
|---|---|
| Type | `UNCONDITIONAL` / `CONDITIONAL` / `ANTI-GUARANTEE` / `PERFORMANCE OR SERVICE REMEDY` / `NONE` |
| Trigger condition, in terms the buyer can observe | |
| Window, as real date arithmetic | |
| Remedy: what is returned, by when, by whom | |
| Claim process, step by step | |
| Is the claim process harder than the purchase process? | Yes → **BLOCK** / No |
| Does the window span the time to first outcome (§3.2)? | Yes / No → **BLOCK** |
| Redemption exposure agreed by | (named human, dated) |

> **A guarantee raises perceived likelihood only if it is claimable.** Conditions engineered to
> be unmeetable, a window shorter than the first outcome, or a claim path harder than checkout
> are a deceptive guarantee regardless of wording. Where no honest guarantee is possible, state
> plainly what the buyer is risking instead — that is a weaker offer and an intact one.

**No redemption rate, conversion lift or "which type performs best" figure appears here.**
Those are numbers from a practitioner manual describing that operator's businesses.
