## 6. Language, drafted in advance and in exact wording

Improvised phrasing under pressure defaults to arguing.

### Three labels

Form: "It seems like…" / "It sounds like…" / "It looks like…" — **no "I"**, then silence. The word "I" converts a label into a claim they must respond to.

| # | Exact wording | Dynamic it names | Response we want |
|---|---|---|---|
| 1 | "It seems like {{...}}" | | a correction or an elaboration |
| 2 | | | |
| 3 | | | |

> A label that invites a yes or no has failed. Rebuild it.

### Two mirrors

Repeat the last few words of their statement as a question, then **stop**. The silence after a mirror is the working part.

| Trigger phrase we expect | Our mirror |
|---|---|

### Five calibrated questions

Open with **how** or **what**. Avoid **why**, which reads as accusation in most commercial contexts.

| # | Question | Predicted answer A → our follow-up | Predicted answer B → our follow-up |
|---|---|---|---|
| 1 | "How am I supposed to do that?" | | |
| 2 | "What about this does not work for you?" | | |
| 3 | | | |
| 4 | | | |
| 5 | | | |

> Remove any question that is an argument with a question mark attached. If it cannot be answered honestly by the counterparty without conceding, it is a trap, not a question.

### Accusation audit

Everything they could reasonably hold against us, said **first**, in their terms:

> "{{Before you tell me your position, let me say what you are probably thinking. {{the worst of it}}.}}"

**Then stop. Do not follow it with a defence.**

- [ ] The audit names the **largest genuine** objection, not a smaller decoy. Naming a small problem to distract from a larger one is a manipulation, not the technique.
