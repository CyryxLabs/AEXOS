The premise

The command line is where the intelligence lives. Everything else observes it.

  1. 01

    CLI first

    Execution, decisions and automation. A capability that does not work here does not exist yet.

  2. 02

    Observability second

    Dashboards watch what the CLI is doing. They never drive it, and are never required to operate it.

  3. 03

    UI third

    Point management and visualisation, where a screen genuinely beats a command.

The expertise is in the procedure

Workflows are composed of connected tasks, not connected agents. A task declares its inputs, its outputs and the checklist it must pass. The agent is a router; swap it and the method is unchanged.

Agent
A role with a persona, a scope of authority and a list of procedures it may run.
Task
An executable procedure with declared inputs, outputs and an exit checklist. The method lives here.
Template
The shape of the document the task produces.
Checklist
The validation a task must pass before it counts as done.
Data
The knowledge base a task reads from — reference tables, signal lists, decision models.
Workflow
A sequence of connected tasks, with the conditions for moving between them.

A validated task is binding: it runs as configured, with its dependencies respected, regardless of who executes it — an agent, a worker or a human.

Method, not impersonation

Every specialist applies a published method and names it. That is load-bearing, not decorative: an agent that follows a named method can be audited against the source, while an agent doing celebrity impersonation has nothing to be verified against.

Cited, not channelled

An agent declares the work its method comes from. Ask why it recommended something and the answer traces to a page you can open.

Honest where there is no text

Where a role rests on a discipline with no canonical work, it says so instead of manufacturing an authority. A wrong attribution is worse than none.

Numbers are not recalled

Figures from the source works are read from the publication or left unstated. A coefficient quoted from memory is a defect, not a detail.

Evidence has a class

A practitioner heuristic supports construction and sequencing. Only measured data supports a magnitude. Stating one in the voice of the other is a blocking error.

The framework validates itself

A contract with no gate stops being a contract. These run in CI, and warnings are treated as failures — each one names a missing field, a stale reference or a deprecated shape.

  • ✓ Squad manifests validate against the JSON schema
  • ✓ Every dependency an agent declares resolves on disk
  • ✓ Every shipped YAML parses
  • ✓ Manifest identity agrees with the definitions it describes
  • ✓ Generated registries are byte-reproducible
  • ✓ Agent definitions, IDE sync and skill export stay in step
  • ✓ Install manifest hash matches the tree

Install

Node 18 or later. The installer scaffolds the core, the squads and the routing registry.

Install into a project

$ npx github:CyryxLabs/AEXOS install

Check the installation

$ aexos doctor

Open the orchestrator

@aexos-master

Ask the orchestrator for something and it reads the registry, matches the domain and routes to the squad that owns it. Push, release and MCP configuration stay the exclusive authority of one agent, by design.
