MAAX Protocol Layers

Memory Core

Context Intelligence

Graph-based context engine mapping file relationships, schemas, routes, dependencies, and documentation for precision prompt assembly.

AI Squads

Command Units

Validation Layer

Command Gates

Audit Layer

Developer Quick Start

CLI Installation & Commands

Initialize MAAX Studio / AEXOS in any project with zero configuration friction.

# Create a new AI-orchestrated project
npx aexos-core init my-project

# Install in an existing codebase
cd my-existing-project && npx aexos-core install
# Activate specific agents via CLI shortcuts
/aexos-dev "Implement user authentication middleware"
/aexos-qa "Run unit tests and security audit"
/aexos-architect "Review API schema compliance"
# Story-Driven Development (SDC) workflow
aexos sdc plan docs/framework/epics/core-super-update/STORY-1.md
aexos sdc next STORY-1.1
# Run automated quality gates before merge
npm run lint && npm run typecheck && npm test
aexos doctor --json
